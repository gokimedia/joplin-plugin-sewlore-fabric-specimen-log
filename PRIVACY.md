# Privacy

Fabric Specimen Log 1.0.0 performs calculations locally. It has no fetch requests, telemetry, advertisements, account login, payment, or automatic update logic.

User-entered specimens and notes are stored in this plugin's private Joplin setting. Export copies the log to the system clipboard only after the export command. A summary command creates an ordinary note in the selected notebook; Joplin can sync that note according to the user's existing settings. The plugin itself does not connect to Sewlore or any third-party service. The listing homepage is documentation, not a runtime dependency.

Removal requires the selected specimen ID and an explicit confirmation. The plugin never deletes ordinary notes. Preserve a CSV backup before uninstalling or changing the Joplin profile; this plugin is not a backup service.
